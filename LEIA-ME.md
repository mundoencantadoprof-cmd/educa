# Coleção Mundo Encantado

Site da Coleção Mundo Encantado (mundoencantadoeduca.com.br) e app Alfabetizando.

- Raiz: páginas do site. Cada mudança na `main` publica sozinha no GitHub Pages (mundoencantadoeduca.com.br) pelo workflow "Publicar o site".
- `app-alfabetizando/`: app **Android** (Google Play). Cada mudança nessa pasta gera o APK de teste.
- `app-alfabetizando-iphone/`: app **iPhone** (App Store). Cada mudança nessa pasta confere se o app compila; o envio à Apple é pelo botão Actions > App iPhone > Run workflow.

As duas versões do app são separadas: atualizar uma não muda a outra.

O domínio e o certificado são configurados em Settings > Pages.
